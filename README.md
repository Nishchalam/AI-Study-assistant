# AI Study Assistant

An AI-powered study assistant designed to help learn and practice Artificial Intelligence, Machine Learning, Deep Learning, and Large Language Models.

## Current Features

- Gemini API integration
- Concept explanation
- Practice question generation
- Adaptive learning
- Technical interview preparation

## Tech Stack

- Python
- Google Gemini API
- google-genai
- python-dotenv

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
